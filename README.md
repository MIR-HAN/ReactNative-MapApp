# <img src="src/assets/screenShots/Logo.png" width="40" height="40" valign="middle"> Maple - Local Produce & Farm Tracker

**Maple** is a community-driven mobile application designed to bridge the gap between local producers and consumers. Whether it's a farm-gate shop, a seasonal harvest stand, or a local producer's point, Maple allows users to discover, pin, and share these fresh food locations on a map.

Support local producers and find the freshest products directly from the source!

---

## ✨ Features

- 📍 **Explore:** Discover local farm stands and producers near your current location.
- 📸 **Contribute:** Found a new producer? Take a photo and pin their location for the community.
- 🔐 **Secure Auth:** User authentication and profile management via Firebase.
- 🌍 **Real-time Map:** Live updates and interactive markers powered by Cloud Firestore.
- 🎨 **Modern UI:** Minimalist and intuitive design using Iconsax and smooth animations.
- 🛠 **Permissions:** Integrated camera and location access management.

## 🛠️ Tech Stack & Dependencies

### **Core**
- **React Native (0.76.3)**: Cross-platform mobile framework.
- **JavaScript (ES6+)**: Core logic and component development.

### **Backend & Storage**
- **Firebase Auth**: User registration and login.
- **Cloud Firestore**: Real-time database for syncronizing locations.
- **Async Storage**: Local persistence for app data.

### **Navigation & UI**
- **React Navigation**: Stack and Bottom Tab navigation.
- **Iconsax & SVG**: Scalable vector icons.
- **RN Animatable**: UI transitions and effects.
- **RN BootSplash**: Splash screen management.

### **Map & Hardware**
- **React Native Maps**: Map integration and custom markers.
- **Geolocation**: Precise user positioning.
- **Image Crop Picker**: Camera and gallery access for produce photos.
